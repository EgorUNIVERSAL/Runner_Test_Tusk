# Runner Test Tusk

Тестовый Unity-проект мобильного раннера по мотивам первого уровня **Rich Inc.**

## Требования

- Unity `6000.2.6f2`
- Universal Render Pipeline


## Запуск

1. Клонировать репозиторий.
2. Открыть корневую папку проекта в Unity Hub с Unity `6000.2.6f2`.
3. Открыть сцену `Assets/Project/Scenes/Level_1.unity` и запустить Play Mode.

Generated-файлы Unity и готовые APK не хранятся в репозитории.
